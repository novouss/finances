# novouss' Finance Tracker

## Background

My finance tracker was originally inside a spreadsheet, while it was maintained for over a year and a half with over thousands of collected transactions. It had a scaling problem and system limitations that left me unsatisfied. Thus, I used my knowledge as a backend developer and data analyst to create this repository, mainly for myself. The backend system is - unconventional to say the least, system diagrams are located inside their respective directories.

This is not a repository that connects to your private banks or digital banks for automatic transaction tracking. You input your transactions consciously and manually. The backend and frontend directories are separated so you can make your tracker and design it the way you want.
